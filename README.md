# 🍗랭킹닭컴 텍스트 리뷰 분석을 통한 브랜드 키워드 파악

## 1. 프로젝트 배경
랭킹닭컴은 다양한 브랜드의 닭가슴살과 건강식품을 판매하는 사이트입니다. 그러나 소비자 입장에서는 각 브랜드의 특징이나 제품의 장점을 비교하기 어려워, 주로 판매량 순위나 별점에 의존하는 경향이 있습니다. 이에 판매량이나 별점 같은 정량적 정보 외에도 소비자 텍스트 리뷰를 분석하면 브랜드별 특징과 장점을 파악할 수 있다고 생각했습니다. 이를 통해 소비자의 합리적 구매를 돕고, 기업은 브랜드의 개선점을 파악할 수 있는 유용한 데이터를 얻을 수 있다고 판단했습니다.

## 2. 주요 분석 방법
자체 브랜드 평가 지표인 **상대적 키워드 빈도**를 도입하여 키워드 빈도를 기준으로 분석하였습니다.

## 3. 인사이트 요약
|분야|인사이트|
|------|----|
|맛|랭킹닭컴 내 순위와 맛 키워드 순위 불일치 (평균 2.14위의 순위 차이)|
|배송|배송 문제로 인해 상위 5개 브랜드 중 2~4위의 순위 변동 |
|상위권 브랜드 vs. 하위권 브랜드|상위권 브랜드는 하위권 브랜드에 비해 배송 불만이 1.2배 높았고, 하위권 브랜드는 상위권 브랜드에 비해 맛 불만이 1.9배 높았습니다. 각 브랜드들은 맛 개선, 배송 불만 개선이 시급해보입니다.|
